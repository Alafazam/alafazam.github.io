## Headings, lists, and emphasis

- Bullet points work
- So does *italic* and **bold** text
- And [inline links](https://alafazam.com)

## Code blocks

Fenced code is syntax-highlighted:

```ts
function greet(name: string): string {
  return `Hello, ${name} — welcome to the blog.`;
}
```
