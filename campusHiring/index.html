Campus Hiring — Network Audit

Download and run one read-only script to report this machine’s network activity over the last 5 hours.

Operating system not recognised — pick the matching card below.

Windows

windows-network-audit.ps1

Download script

Needs an elevated PowerShell — right-click PowerShell and choose "Run as Administrator", or several event logs will be unreadable.

  1. 1Go to the folder the file downloaded into
    cd $env:USERPROFILE\Downloads
  2. 2Allow the downloaded script to run in this session only
    Set-ExecutionPolicy -Scope Process Bypass -Force; Unblock-File .\windows-network-audit.ps1
  3. 3Run the audit
    .\windows-network-audit.ps1 -HoursBack 5

Fastest path — one command, no download

This fetches and executes a remote script, which is only acceptable here because the domain is mine and the source is the file linked above.

powershell -NoProfile -ExecutionPolicy Bypass -Command "& ([scriptblock]::Create((irm https://alafazam.com/audit/windows-network-audit.ps1))) -HoursBack 5"

Report is written to Desktop \ NetworkAudit-<COMPUTERNAME>-<timestamp>.txt

macOS

mac-network-audit.sh

Download script

Run it with sudo. `log show` also needs Full Disk Access for Terminal (System Settings → Privacy & Security → Full Disk Access) or the log sections report as unreadable.

  1. 1Go to the folder the file downloaded into
    cd ~/Downloads
  2. 2Restore the executable bit, which downloading strips
    chmod +x mac-network-audit.sh
  3. 3Run the audit
    sudo ./mac-network-audit.sh --hours 5

Fastest path — one command, no download

This fetches and executes a remote script, which is only acceptable here because the domain is mine and the source is the file linked above.

curl -fsSL https://alafazam.com/audit/mac-network-audit.sh | sudo bash -s -- --hours 5

Report is written to ~/Desktop/NetworkAudit-<hostname>-<timestamp>.txt

What this reports

Show this section to the candidate before running the script.

Collected

  • Every network connect and disconnect in the window, wired, wireless or tethered.
  • DHCP and lease activity, which is hard evidence that a network was actually joined.
  • Wi-Fi association timeline and the names (SSIDs) of networks connected to.
  • Total bytes sent and received per network interface, counted since the machine booted.
  • Tethering or dongle hardware attached during the window — phone USB, Bluetooth PAN, RNDIS adapters.
  • Whether the system logs were cleared or truncated, which would make the rest unreliable.
  • Saved Wi-Fi network names already stored on the machine.

Not collected

  • No page content, URLs, search history or browser data.
  • No keystrokes, screenshots, screen recording or webcam access.
  • No files, documents or personal data are read or copied.
  • No message, email or chat content.
  • Nothing is uploaded anywhere — the report is written only to this machine’s Desktop.

Where the report lands

  • WindowsDesktop \ NetworkAudit-<COMPUTERNAME>-<timestamp>.txt
  • macOS~/Desktop/NetworkAudit-<hostname>-<timestamp>.txt
  • Linux~/Desktop/NetworkAudit-<hostname>-<timestamp>.txt

One file per run, timestamped, so each candidate leaves exactly one artifact. The scripts also print the same report to the console.
